# BDPL V2 — Professional Auction & Tournament Platform

## V2 features
- IPL-style dark/gold auction room
- Player photo cards
- Real-time Socket.IO auction
- Countdown auction timer
- Bid resets timer
- Team purse validation
- Squad-size validation
- Sold/unsold workflow
- Franchise team management and logo upload
- Player registration with photo upload
- Live match centre
- Ball-by-ball quick buttons: dot, 1, 2, four, six, wicket
- Runs/wickets/overs
- Striker, non-striker and bowler fields
- Points table management
- NRR, wins, losses, ties and points
- Player runs/wickets leaderboard
- Tournament schedule/match management
- Public responsive website
- Owner-only control centre
- SQLite persistence

## Run
```bash
npm install
npm start
```
Public site: http://localhost:5000
Owner panel: http://localhost:5000/admin.html

Create `.env` from `.env.example` and change the owner password and JWT secret before deployment.
